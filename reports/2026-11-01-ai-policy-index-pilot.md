Limits: local rule indexes/categories, backlinks, project-talk and other namespaces were not systematically exhausted; multilingual special sites were not searched in every language; family-specific OCR/machine-translation vocabulary was not separately searched. Meta’s substantive policies often live in mainspace, which its project/help keyword query did not cover. A single broad OR query can be dominated by archives or deletion requests, especially on Commons and Wikidata.

API accounting: 65 command-level attempts, 1 failed attempt. The initial German Wikivoyage namespace request failed because of local DNS/sandbox access; a subsequent permitted request succeeded. No source-site rate limits or unrecovered API failures were recorded. Requests were serial in each collection process, with a 0.5-second pause and at most two processes briefly overlapping; no automatic retry loop was used. The render calls emitted a `prop=sections` deprecation warning but returned usable text. Supplemental web retrieval failed for English Wiktionary/Wikiquote and a guessed Commons title, and one Commons follow-up timed out; direct API source checks were used where applicable. Internal web-tool requests/retries are not visible and are excluded from the API count.
